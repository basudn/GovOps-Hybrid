# Architectural Decision Records (ADRs)

This directory contains the Architectural Decision Records (ADRs) for the GovOps project. An ADR is a short document that captures a single, significant architectural decision, along with its context and consequences.

Using ADRs allows us to keep a transparent, historical record of the key design choices that have shaped this framework.
