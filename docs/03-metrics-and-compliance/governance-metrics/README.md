# GovOps Metrics

GovOps metrics are designed to provide a new level of visibility into the security and risk posture of an organization. By leveraging the runtime observability features of the GovOps framework, these metrics can provide real-time insights into the system's behavior.

## Philosophy

The philosophy behind GovOps metrics is to move beyond traditional, static security metrics and to provide dynamic, actionable insights that can be used to steer the organization's risk management strategy. This is analogous to the role that metrics like Mean Time to Recovery (MTTR) play in the DevOps world.

## Data-Driven

GovOps metrics are data-driven, based on the runtime data captured from capability IDs. By mapping risk data to actual runtime events, organizations can gain a better understanding of the "current" of their digital environment.
