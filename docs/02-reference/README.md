# Reference

This section is the technical reference material for GovOps: the architecture, the individual
services, the information model, interfaces, security considerations, and glossary. Unless a page
explicitly says otherwise, everything here is **informative** rather than normative — see
`./conformance/README.md` for why binding conformance criteria do not yet exist.

- [Architecture](./architecture/README.md) — the two-plane model, GovOps loop, four functional
  layers, capability lifecycle, and C4-style system-context/component views.
- [Components](./components/README.md) — the individual GovOps services, one page each.
- [Information Model](./information-model/README.md) — core identifiers, decision model, policy
  model.
- [Interfaces](./interfaces/README.md) — the contracts between components, and which ones are
  still undefined.
- [Security](./security/README.md) — cross-cutting security and trust rationale.
- [Conformance](./conformance/README.md) — current non-normative status and why.
- [Terms and Definitions](./terms-and-definitions/README.md) — glossary of GovOps vocabulary.
