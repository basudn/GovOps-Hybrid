## Planned tutorials

- Define a policy and trace its decision evidence back through the Runtime Authorization Context

  `../03-metrics-and-compliance/compliance-path/gemara-to-oscal.md`
- Add or revise an architecture decision record, following the existing pattern in

These are learning-oriented, hands-on walkthroughs, distinct from the how-to guides planned in
`../04-how-to-and-process/README.md`, which will be task-oriented rather than learning-oriented.
