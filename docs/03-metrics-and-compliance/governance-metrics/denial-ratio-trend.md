# Denial Ratio Trend

## Description

The "denial ratio trend" is a metric that tracks the ratio of denied access requests to total access requests over time. This can be a useful indicator of potential security issues, such as misconfigured policies, malicious activity, or a sudden change in application behavior.

## Calculation

The denial ratio is calculated as follows:

```
Denial Ratio = (Number of Denied Access Requests) / (Total Number of Access Requests)
```

The trend is then tracked over time to identify any significant changes or anomalies.

## Interpretation

- **A sudden spike** in the denial ratio could indicate a brute-force attack or a misconfigured client.
- **A gradual increase** could suggest a problem with policy drift or a change in user behavior.
- **A low, stable denial ratio** is generally a sign of a healthy system.

## Use Cases

- **Security Monitoring:** This metric can be used as an input for security monitoring and alerting systems.
- **Policy Tuning:** The denial ratio trend can help identify policies that are too restrictive or that are not working as intended.
- **Risk Management:** This metric can be used to track the effectiveness of risk mitigation strategies.
